F2L uses the public “Best F2L Algorithms” PDF linked from that page, updated August 8, 2021: https://drive.google.com/file/d/1nzAXYUWZJ6H2wIOXaHdWXep3W57tArbR/view. Basic cases are from pages 2–5; numbering follows document order, not a universal F2L numbering scheme. Each case retains its source/page. Move sequences and case/group facts were transcribed; reference JavaScript, PDF content, and artwork are not distributed. SVG previews are generated independently from the local geometric cube model.

Notation is normalized: parenthetical repetitions expand, inverse half turns become ordinary half turns, and the source Ub alternate's R3 becomes R'. Every reference variant passes parser-token equality and KPuzzle inverse/setup round trips. These checks do not independently establish all standard case identities. Personal alternates are notation-checked; the user remains responsible for assigning them to the correct case.

Browse by section, group, learning status, or notation/name search. Each case has a preferred alternate. Add a preferred variant, any individual alternate, or all visible preferred variants to the session. Multiple alternates of the same case can coexist. A session entry snapshots case ID plus variant ID; a later preference change does not replace an existing entry. Balanced mode draws each entry once per cycle; adaptive mode prioritizes slow/difficult variants using recorded statistics. Training applies the inverse of the selected variant as its guided case setup. These case setups are separate from the timer's official full-cube random-state scrambles.

Preferences, custom variants, learning status, and session selections persist in localStorage. Stable compatible starter IDs retain prior history; mislabeled starter cases are not propagated. Attempts retain case/variant IDs, intended algorithm, setup, session ID, starting grip, actual moves, timestamps, and pauses. Per-variant rolling recognition/execution/mistake statistics support later comparison. AI recommendations, handedness-aware ranking, and external analysis are not implemented; nothing is sent to an AI service automatically.

F2L previews highlight only the target corner/edge and two reference centers, using white/green/red with unrelated stickers blanked in gray. The displaced pair’s destination is normalized to the front-right slot, outlined with dashes. Larger convex isometric diagrams and F/R labels improve recognition. This diagram palette is independent of the saved solving grip and does not change move tracking.
